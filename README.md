# Parking-Mangement-using-Nxsys-DDR-FPGA-Board
The system tracks the occupancy of parking slots and provides immediate visual feedback. It manages entry/exit logic, counts available spaces, and updates the on-board displays to inform drivers of the current status
Key Hardware Components
FPGA Board: Nexys 4 DDR (Artix-7 XC7A100T).  
Inputs: * Slide Switches (SW0–SW15): Simulate infrared (IR) sensors for each parking slot.  
Push Buttons: Used for system reset or manual gate override.
Outputs:7-Segment Display (8 digits): Shows real-time messages like FULL, OPEN, or specific slot counts.
